# Image assets

The homepage uses original photographs hosted in the official WordPress media library at `almuhanad.com`. The preview references these original URLs directly so image attribution and source resolution remain intact. The execution container could not download external image binaries, so the photographs are not mirrored in this folder.

See `image-sources.json` for each exact URL and intended use. For offline hosting, download these originals into this folder and update the `src`/`href` paths in `index.html`.
